# Antigravity Monitor banners

The v1.1.0 repository includes three 1600 x 900 PNG banners matching the `data-terminal` palette: `antigravity-monitor-hero.png`, `antigravity-monitor-features.png`, and `antigravity-monitor-customization.png`.

They contain no version text and preview the live v1.1.0 dashboard tabs (`overview.png`, `models.png`, `threads.png`, `settings.png`), inline composer card (`card.png`), and composer pill (`badge.png`).

`banners.html` holds the editable HTML template for the customization banner. Screenshot values and reset countdowns reflect capture time and change during use. Native macOS and Linux runtime execution require platform acceptance testing.
