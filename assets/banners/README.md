# Antigravity Monitor banners

The v1.0.0 repository includes three reusable 1600 × 900 PNG banners: `antigravity-monitor-hero.png`, `antigravity-monitor-features.png`, and `antigravity-monitor-customization.png`.

The images contain no version text. Their UI comes from actual captures of the running Windows white app and local companion on 6 November 2026. The app was on a new thread, so the card shows Ready and actual quota observations. No populated conversation, context percentage, or fictional telemetry was added.

`banners.html` contains the editable typography and composition. It references the unmodified screenshot crops under `docs/screenshots` and the SVG-derived project logo under `assets/branding`. Screenshot values and reset countdowns reflect capture time and will change during use.

The artwork does not demonstrate native macOS/Linux operation. Those implementations need native acceptance testing. See the project audit for validation scope.
