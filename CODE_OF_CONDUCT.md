# Code of conduct

Everyone participating in Antigravity Monitor discussions, issues, and pull requests should be treated with respect.

Keep feedback specific and constructive. Welcome different experience levels and backgrounds. Disagreement about code is normal; harassment, threats, discrimination, personal attacks, and publication of another person's private information are not acceptable.

Maintainers may edit or remove inappropriate content, close discussions, or restrict participation when needed. Report concerns privately through an available maintainer contact or GitHub's reporting tools. Do not publish private details to make a report.

This policy applies in project spaces and when representing the project elsewhere.
