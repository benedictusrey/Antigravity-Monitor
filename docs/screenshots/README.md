# Actual UI captures for v1.0.0

These images were captured on 6 November 2026 from the running Windows white Antigravity app and installed local companion. Dashboard pages used the live HTTP snapshot stream. The card, expanded customization controls, composer, and quota-group crops came from the actual rendered UI. No sample telemetry or invented conversations were substituted.

The app was on a new thread at capture time. The images therefore show Ready and live quotas rather than a fabricated context percentage. Preferences and conversation selection were preserved. Account masking remained enabled.

`card.png`, `customization.png`, and `badge.png` show the white-app bridge. `overview.png`, `sessions.png`, `models.png`, and `settings.png` show the shared dashboard in the actual companion. `companion.png` is the same current overview capture. `quota-group-1.png` and `quota-group-2.png` are direct element crops from that live overview.

The three banners in `assets/banners` compose these captures with typography and the project logo. They contain no release version text. Values and reset times are observations at capture time and will change during use. The files do not demonstrate native macOS/Linux execution or native editor activation.
